# DMIT 控制面板怎么用？新手必看的完整操作指南

第一次登进 DMIT 后台，很多人会愣一下——界面比想象中简洁，但功能藏得比较深，不点进去根本不知道在哪。

## 控制面板入口在哪，怎么登录

DMIT 用的是自研控制面板，不是 SolusVM 也不是 Virtualizor，所以从其他家迁过来的用户会有点不适应。

登录地址是 `my.dmit.io`，注册时填的邮箱就是账号。登进去之后看到的是 Client Area，左侧导航分成几个大块：Services（你的服务器列表）、Billing（账单与余额）、Support（工单）、Account（账户设置）。

买完机器之后，在 Services → My Services 里找到对应的 VPS，点进去就是单台机器的管理页面。这里才是真正的控制面板核心区域。

## 单台 VPS 的控制面板能做什么

点进单台机器之后，能看到几个常用操作区：

**基础操作**
- Power On / Off / Reboot：开关机和重启，按钮响应速度挺快，一般 10 秒内生效
- Reset Password：重置 root 密码，操作后会发邮件，不是即时显示在页面上
- Reinstall OS：重装系统，支持多个 Linux 发行版，Debian / Ubuntu / CentOS Stream 都有，部分套餐还有 Windows 选项

**网络信息**
- IP 地址、子网掩码、网关、DNS 都在这里查
- 部分套餐会显示当前月流量用量和剩余额度，走的是实时统计，延迟大概在几分钟以内

**VNC 控制台**
这个功能我自己用过几次，主要是 SSH 连不上的时候救急用。点开之后会弹出一个网页版 VNC 窗口，延迟比较高，但能用。如果系统挂了或者防火墙把自己锁在外面，这是唯一的救命稻草。

**流量包与 IP 管理**
部分套餐支持购买额外流量包，在控制面板里直接操作，不用开工单。IP 相关的操作（比如申请额外 IP）也在这里，但不是所有套餐都开放。

## 账单和余额怎么管

Billing 区域分成几个子页面：

- **Add Funds**：充值入口，支持支付宝、PayPal、加密货币等方式，充进去的余额会存在账户里，下次续费自动扣
- **Invoices**：历史账单，每张都能下载 PDF
- **Auto Renew**：在 Services里每台机器单独设置，不是全局开关，这点要注意——新买的机器默认不一定开了自动续费，建议买完就去确认一下

余额不足的时候系统会发邮件提醒，但提前量不算太大，建议账户里保持一点余额缓冲，别等到欠费停机再充。

## 工单系统和客服响应

Support → Open New Ticket，选对应的部门提交。技术问题选 Technical Support，账单问题选 Billing。

响应速度这块，我自己的体感是工作时间内一般几小时内有回复，非高峰期有时候更快。工单支持中文，直接用中文写没问题，不用担心语言障碍。

## FAQ

### DMIT 控制面板支持中文界面吗？

目前控制面板界面是英文的，没有中文切换选项。不过操作逻辑比较直观，常用功能就那几个按钮，用一两次就熟了。工单支持中文回复，语言不是障碍。

### 重装系统会清空数据吗？

会。Reinstall OS 是完全重装，原有数据全部清除，操作前务必备份。控制面板在点击确认之前会有一次弹窗提示，别手快点过去。

### 控制面板里看不到流量统计怎么办？

部分套餐的流量统计显示在机器详情页的侧边栏，有时候需要往下滚动才能看到。如果确实没有显示，可以开工单问客服，也可以在机器内部用 `vnstat` 自己统计。

### 忘记 root 密码怎么找回？

在控制面板的机器详情页点 Reset Password，系统会重新生成一个随机密码发到注册邮箱。注意查收邮件，有时候会进垃圾箱。

### DMIT 支持哪些付款方式？

支付宝、PayPal、加密货币（USDT 等）都支持，充值进账户余额后统一扣费。国内用户用支付宝最方便，汇率按当时实时价格换算。[👉 充值并选购 DMIT 套餐](https://www.dmit.io/aff.php?aff=18446&aff_sub1=faq-payment)

### 机器开不了机或者 SSH 连不上怎么办？

先去控制面板确认机器状态是否显示 Running，如果状态正常但 SSH 不通，用 VNC 控制台登进去排查防火墙规则。如果机器状态异常，先尝试 Reboot，不行就开工单，描述清楚机器 IP 和故障现象，响应还是比较及时的。

### 套餐到期前多久会提醒续费？

系统会在到期前发邮件提醒，但建议自己在 Services 里确认一下 Next Due Date 和 Auto Renew 状态。自动续费需要账户余额充足，余额不够的话即使开了自动续费也会失败，然后机器进入暂停状态。
